# Source B — Zero Trust Remote Access Migration Policy v4.1

> Synthetic conference example. Not a real corporate policy.

- Effective date: 2026-09-01
- Branch-office full-time employees using a company-managed device migrate to Zero Trust Remote Access.
- Zero Trust authentication uses Entra ID + Conditional Access.
- For this group, the Legacy VPN credential flow is no longer the primary troubleshooting path.
- Headquarters employees remain on Legacy VPN during phase 1.
- Contractors remain on Legacy VPN during phase 1.
- This policy only supersedes the Legacy VPN guide for the explicitly migrated population. It does not invalidate the legacy guide for other populations.
- If employee type, office, or device-management state is unknown, support should clarify before selecting a procedure.
