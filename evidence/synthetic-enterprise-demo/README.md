# 企業知識整合合成範例

這組資料用於 LLM Wiki 演講與本機示範。七份來源依企業知識問答常見的問題結構重新編寫；組織、系統、權限、流程、錯誤碼、日期及操作步驟均為虛構教學設定，不代表任何企業現行政策，也不提供真實系統操作入口。

六份基準來源已依既有 llm-wiki-example 流程完成草稿編譯。v1 十題契約的兩階段實際問答均為 8／10 題通過。後續凍結 v2 十一題契約並重新執行兩階段問答，結果為 Baseline 10／11、Updated 9／11；題數、規則與回答均不同，不能將兩版分數當成同一次實驗的前後變化。原始失敗保留，知識草稿尚未通過回歸、人審或發布。

## 實驗進度

- [v1 十題實際問答與更新回歸結果](records/experiment-summary.md)：已執行，兩階段均有引用契約缺漏；更新後另有說明與格式問題。
- [十題測試契約與判讀方式](contracts/README.md)：已定義情境、基準／更新後預期、必要引用與禁止推論；契約保持凍結，實際結果另存。
- [來源 preflight 紀錄](records/ingest-preflight.json)：沿用既有 `llm-wiki-example` 工具，記錄核可前的 `review_ready` 狀態；使用者已核可六份確切 digest，正式准入紀錄見 [核可提案](records/source-admission-proposal.json)。
- [基準編譯結果](records/baseline-summary.md)：六份來源、18 頁草稿、17 項 claim；既有 Wiki lint 通過，十題靜態覆蓋完成。

## 示範順序

1. 以 `SRC-01` 至 `SRC-06` 建立基準知識快照；示範情境日期為 `2030-02-01`。
2. 加入生效日為 `2030-03-01` 的 `SRC-07`；更新後情境日期為 `2030-03-02`。
3. 要求模型提出受影響頁面、claim、適用條件與引用的變更提案。明確的取代聲明及條件是判斷依據；日期只是其中一項資訊。
4. 審查提案是否保留服務台 fallback、密碼到期流程與其他政策，再執行相同問題的回歸。
5. 保存提案、人工修正、知識 diff 與實際回答；實際完成前維持待執行狀態。

`2030` 年日期是虛構時間軸。示範執行時應明確傳入情境日期，避免系統依電腦當日日期把所有來源視為尚未生效。

## 預期回歸行為

| 情境 | 預期行為 | 主要依據 |
|---|---|---|
| 更新後：正式員工、公司管理筆電、已註冊自助復原，確認帳號鎖定 | 優先引導虛構的自助復原流程；失敗時轉服務台。 | `SRC-07` |
| 更新後：承包商確認帳號鎖定 | 保留服務台流程，不套用正式員工分支。 | `SRC-03`, `SRC-07` |
| 更新後：受管理裝置但尚未註冊自助復原 | 保留服務台流程；裝置受管理不等於已註冊。 | `SRC-04`, `SRC-07` |
| 更新前：符合自助條件但確認帳號鎖定 | 使用基準服務台流程，不提前套用新規則。 | `SRC-03`, `SRC-07` |
| 只有 `DEMO-101`，未確認原因與使用者條件 | 先釐清原因與必要條件，不直接診斷為帳號鎖定。 | `SRC-01`, `SRC-02` |
| 公司管理筆電密碼到期 | 保留密碼更新流程與公司網路條件；自助解鎖不等於改密碼。 | `SRC-01`, `SRC-02`, `SRC-07` |
| 分公司支援人員已連上 VPN，想使用 TeamShare | 說明遠端路徑限制，不能只提供一般權限申請步驟。 | `SRC-04`, `SRC-05` |
| 接入模式、角色或裝置狀態未知 | 先追問，不自行補足適用條件。 | `SRC-04`, `SRC-05`, `SRC-07` |
| 國外臨時接入申請缺日期或核准 | 補齊申請條件並保留核准流程；不聲稱已開通。 | `SRC-06` |
| 詢問未記載的 `DEMO-999` | 說明來源未提供對應原因與處置，收集非機密錯訊後轉服務台。 | `SRC-01`, `SRC-02` |

這些案例僅驗證本資料集的行為邊界；通過它們不代表整體準確率提升、真實企業政策驗收或存取控制已實作。

## 公開資料邊界

- `example.com` 網址是占位值，不是可操作的企業服務。
- 文件不包含企業原件、原件雜湊、內網位址、真實聯絡人或實際帳號。
- 來源間的相對連結及 `SRC-*` ID 僅用於這份合成資料集的追溯。
- metadata 與文件內的角色限制是教學內容，不構成檢索 ACL 或系統權限實作。
- 如另加入企業資料、截圖、回答紀錄或執行 log，應重新檢查公開範圍；本資料集的合成標示不會自動涵蓋那些新增內容。
