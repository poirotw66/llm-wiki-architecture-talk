# Purpose

## Mode

template

## Goal

Compile and query a bounded draft knowledge snapshot for a synthetic enterprise presentation example. Preserve partial supersession, provenance, eligibility, clarification and retained procedures.

## Scope

- Active updated snapshot: SRC-01 through SRC-07; scenario date 2030-03-02.
- Initial baseline: SRC-01 through SRC-06 at 2030-02-01, retained separately in baseline-v1.
- Historical events use policy effective at the event date. Unknown event_date in a case uses the explicitly supplied phase date; a genuinely unknown date must be clarified.
- Source admission is approved; compiled content and answers remain draft pending human review.
- Synthetic public teaching data only. No production access, real enterprise data, retrieval ACL enforcement or actual recovery operation.

## Answer Completeness

- When a policy changes a first action, state the effective-date boundary and each source-supported eligibility condition in the user-facing answer. Do not replace the conditions with a shorthand assertion that the user qualifies; if a required condition is unknown, ask for it before selecting a path.
- When recommending a procedure that depends on a prerequisite, state the source-supported fallback if that prerequisite becomes unavailable or the procedure cannot be completed. Keep the fallback distinct from the first action that applies to the stated situation.
- Include only conditions and contingencies relevant to the user's question. Cite the canonical sources for material claims; citation text does not replace the user-facing explanation. Do not infer an action, approval or completed recovery from a draft knowledge page.

- Which password-expiry, resource and overseas procedures remain unchanged?
- Which information must be clarified and where is the evidence boundary?
